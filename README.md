# Журнал тренировок

Веб-приложение на основе исходного файла «Журнал тренировок.html». Интерфейс и логика разделены на HTML, CSS и JavaScript.

## Возможности
- планы тренировок, запись подходов, история и календарь;
- таймер отдыха, графики прогресса, профиль и замеры;
- адаптивное отображение на телефонах, планшетах и компьютерах;
- ИИ-тренер через OpenAI Responses API;
- резервное копирование и восстановление журнала.

## Локальный запуск
1. Установите Node.js 20 или новее.
2. В корне проекта выполните `npm install`.
3. Скопируйте `.env.example` в `.env`.
4. Заполните `OPENAI_API_KEY` и `OPENAI_MODEL`. Укажите модель, доступную вашему API-проекту.
5. Выполните `npm start` и откройте `http://localhost:3000`.

Без API-настроек журнал работает, но ИИ-тренер будет недоступен.

## Публикация на Render
Создайте Blueprint из этого репозитория. Render использует `render.yaml`. В настройках сервиса добавьте секреты `OPENAI_API_KEY` и `OPENAI_MODEL`, дождитесь Live и откройте выданный HTTPS-адрес.

## Хранение данных
Планы, тренировки, профиль и замеры хранятся в localStorage браузера. Они не синхронизируются автоматически между устройствами. Для переноса используйте встроенную резервную копию.

При отправке вопроса ИИ-тренеру на сервер передаются вопрос, история диалога и данные журнала; сервер отправляет их в OpenAI API. API-ключ хранится только в переменных окружения сервера. Не вносите сведения, которыми не хотите делиться с API-провайдером.
